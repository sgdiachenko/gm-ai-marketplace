# Changelog

All notable changes to `research-tools`. Versions follow [semver](https://semver.org): a new agent is a minor release, a change to an agent's name or report format that callers parse is a major one.

## 1.0.0 — 2026-10-14

### Added

- `researcher` agent: read-only research in the repository (code, docs, git history) or external sources (docs, specs, changelogs), with clarifying questions for vague tasks and a report that always lists what could not be found.
